# 轉換工作評估工具 CareerCal

你的工作決策輔助工具
![轉換工作評估表預覽](public/og-image.png)

[https://careerCal.hannahtw.com/](https://careerCal.hannahtw.com/)

## 亮點

- 把「要不要接受這份工作」拆成 **16 個可量化面向**，分成 5 大類：金錢報酬、職涯發展、工作適配、生活品質、環境穩定性
- 每項給 **1～5 分**，再依 **權重（1～5）** 加權，換算成 **0～100% 的得分率**
- 不確定的面向可以留空，**未評分的項目不列入計算**（不會被當成 0 分）
- 評分、權重、職稱都存在瀏覽器 **localStorage**，不小心關掉也不會遺失
- 得分率自動對應判斷建議（很值得轉 → 不建議轉）
- 一鍵下載成 **Excel（.xlsx）** 評分表

## 評分與判斷標準

```
得分率% = (實際加權總分 − 最低可能總分) / (最高可能總分 − 最低可能總分) × 100
```

**評分**

| 分數 | 意思 |
|------|------|
| 5 | 明顯加分，很有吸引力 |
| 4 | 小加分，可以接受 |
| 3 | 普通，沒有明顯影響 |
| 2 | 略差，但可接受 |
| 1 | 明顯偏差，需要考慮 |

**權重**

| 權重 | 意思 |
|------|------|
| 1 | 幾乎不重要 |
| 2 | 有影響，但不是關鍵 |
| 3 | 中等重要 |
| 4 | 很重要 |
| 5 | 核心關鍵 |

**判斷區間**

| 得分率 | 建議 |
|------|------|
| 75% 以上 | 很值得轉 |
| 60～74% | 偏值得，但要確認風險 |
| 40～59% | 可以考慮，但不是明顯好選項 |
| 25～39% | 只有在你很想離職時才考慮 |
| 低於 25% | 不建議轉 |

> ⚠️ 為避免只填幾項就下結論，**至少要評滿 60%** 才會顯示判斷結果並開放下載評分表。

環境需求：Node 22（見 `.nvmrc`）、pnpm

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm deploy
```
